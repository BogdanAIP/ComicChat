# ComicChat interface worlds — 2026-10-10

The previous themes changed mostly palette. This revision gives Manga, Superhero and Cartoon their own masthead, typography, frame geometry, bubble shape, ink weight, avatar silhouette, control geometry, print/background texture and gutters. The existing messenger and security boundaries are reused.

| World | Visual system |
|---|---|
| Manga | White/black ink, screentone, straight frames, serif inked headings, oval speech, square controls and avatars |
| Superhero | Blue comic masthead, yellow print halftone, thick outlines, angular frames and speech, italic display headings, offset shadows |
| Cartoon | Cloud landscape, rounded hand-shaped frames and avatars, soft speech, drawn controls, dashed frame dividers |
| Classic Ink | Paper palette and print frames retained |
| Anime | Existing flowing interface retained |

Settings uses miniature comic layouts with visible scenes and speech instead of Aa color swatches. The first three styles appear first. RU/EN/AR descriptions explain each choice. App appearance is named separately from conversation illustration style.

Original speech stays canonical, white-backed, at least16px, normal font and high contrast. The original text drawer uses a quiet readable treatment in all worlds. Artwork, generated bytes, message IDs and immutable message style metadata are not regenerated or changed by switching appearance.
